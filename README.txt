LITERA No. 1 웹판
만든 날 2026-11-29 · 판 번호 80287448d4
주소 https://tyooni1.github.io/Litera/

1. 이 폴더
- 독자에게 공개하는 웹판입니다. 웹 주소 하나로 휴대폰, 태블릿, 컴퓨터의 브라우저에서 열립니다. 독자는 파일을 내려받지 않습니다.
- 한 파일짜리 판(Litera_vol1_flipbook.html)은 편집부 확인·보고용으로 따로 둡니다.
- 쪽 그림은 두 크기로 들어 있습니다. 작은 그림 전체 약 20MB, 큰 그림 전체 약 46MB이고, 화면 크기와 확대 정도에 맞춰 지금 보는 쪽과 그 앞뒤 쪽만 받아 옵니다.
- 할 수 있는 것: 책장 넘기기, 차례, 글로 읽기(본문을 글자로, 화면 낭독기로도), 쪽 링크(주소 끝 #p=쪽 번호), 홈 화면에 추가, 이 기기에 저장(약 21MB, 그 뒤로 인터넷 없이 읽기), 새 판 알림.
- 방문 기록, 쿠키, 분석 도구를 쓰지 않고, 이 폴더 밖의 서버에는 아무것도 요청하지 않습니다.

2. 올리는 법 (셋 중 하나)
 가. Netlify Drop: https://app.netlify.com/drop 에 이 폴더를 통째로 끌어다 놓습니다. 바로 주소가 생깁니다. 계정을 만들면 주소를 유지하고 이름을 바꿀 수 있습니다.
 나. GitHub Pages: 새 저장소에 이 폴더 안의 파일을 모두 올리고, Settings → Pages에서 Branch를 main, 폴더를 / (root)로 정합니다. 주소는 https://아이디.github.io/저장소이름/ 입니다.
 다. Cloudflare Pages: 새 프로젝트에서 이 폴더를 올립니다.
- 폴더 안의 파일을 구조 그대로 모두 올려야 합니다. index.html만 올리면 열리지 않습니다.
- 주소가 https로 시작해야 홈 화면에 추가와 저장이 됩니다. 위의 세 곳은 모두 https입니다.
- _headers 파일은 Netlify와 Cloudflare Pages에서 보안·캐시 설정으로 쓰입니다. GitHub Pages는 이 파일을 쓰지 않지만 책은 똑같이 열립니다(같은 보안 설정이 index.html 안에도 있습니다).

3. 주소가 정해진 뒤 (하지 않아도 책은 열립니다)
- 카카오톡 등에 링크를 붙였을 때 표지 미리보기가 확실히 나오게 하려면, 주소를 넣어 다시 만듭니다.
  python3 tools/webreader.py --base-url https://정해진주소/

4. 고친 판을 올릴 때
- 새로 만든 폴더 전체로 바꿔 올립니다(같은 주소).
- 지금 주소(https://tyooni1.github.io/Litera/)는 저장소 tyooni1/Litera의 gh-pages 가지에서 나옵니다. 고친 판은 gh-pages 가지에 올려야 주소에 반영됩니다(main 가지에도 같은 내용이 있습니다). 올린 뒤 1~2분 지나면 바뀝니다. 전에 열어 본 독자에게는 다음에 열 때 ‘리테라를 새로 고친 판이 나왔습니다’라는 알림이 뜨고, 누르면 새 판으로 바뀝니다.
- 바뀌지 않은 쪽 그림은 파일 이름이 같아서 다시 받지 않습니다.

5. 컴퓨터에서 미리 보기
- 이 폴더에서 python3 -m http.server 8000 을 실행하고 브라우저에서 http://localhost:8000 을 엽니다.
- index.html을 더블클릭해서 열면 브라우저가 쪽 파일을 막아 책이 열리지 않습니다. 파일로 주고받을 때는 한 파일짜리 판을 씁니다.

6. 알아 둘 점
- 카카오톡, 인스타그램 같은 앱 안의 브라우저에서도 열리지만 느릴 수 있어서, 위쪽에 안내가 한 번 뜹니다. ⋯ 메뉴의 ‘다른 브라우저로 열기’로 Chrome이나 Safari로 옮길 수 있습니다.
- 아이폰과 아이패드는 Safari의 공유 단추 → ‘홈 화면에 추가’로 설치합니다. Safari에서 오랫동안 열지 않으면 저장한 책이 지워질 수 있습니다(홈 화면에 추가한 경우는 해당하지 않습니다).
- 책에 실린 사진과 그림의 출처는 책 안의 ‘사진과 그림’ 쪽에 있습니다.
